# Amelia Elementor Booking Forms

Custom multistep booking forms for Amelia using Elementor.

## Installation and use

Place the `amelia-elementor-forms` directory in `wp-content/plugins/` and activate **Amelia Elementor Booking Forms** from the WordPress Plugins screen.

Built for sites using Amelia and Elementor to present a multistep booking flow.
